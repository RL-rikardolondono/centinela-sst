# Centinela SST

Sistema de gestión de seguridad y salud en el trabajo (SG-SST) para empresas en Colombia. Una aplicación de **SkyNet Genesis**.

- `docs/`: la aplicación (se publica con GitHub Pages en centinela.skynetgenesis.com).
- `servidor/`: el servidor (Render, plan gratuito) que guarda los datos en PostgreSQL (Neon).
- `render.yaml`: configuración del servidor para Render.

Las claves y contraseñas nunca se guardan en este repositorio: se escriben solo en Render.
